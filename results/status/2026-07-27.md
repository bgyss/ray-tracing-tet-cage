# Implementation status — 2026-07-27

This status artifact applies the cross-cutting audit contract without weakening
the original milestone gates.

## Directly proven

- The macOS host configures the C++20 and Objective-C++ targets with AppleClang.
- Analytical and seeded CPU tests cover barycentric conversion, affine
  deformation equivalence, inverse-transpose normals, all 24 tetrahedron vertex
  orders, reflected and singular tetrahedra, clipping provenance, deterministic
  serialization, shared-face ownership, and uncovered geometry.
- A direct host-driver Metal query identifies one Apple M1 Max and reports ray
  tracing, function-pointer, Metal 3, and Metal 4 support.
- The Metal driver returned acceleration-structure size estimates through
  16,000,000 direct and indirect instances for standard and extended usage.
  This proves only descriptor sizing.
- The Vulkan probe reports the absent SDK/loader as unverified instead of
  emitting mocked device data.

## Partially proven

- Canonical asset format v1 and its serializer exist, but dense smooth/cube
  fixture reconstruction, image comparison, cross-compiler golden files, and a
  broad malformed/fuzz corpus are not yet complete.
- The CPU math/clipping baseline passes current tests, but exact-predicate
  topology decisions and the full centimeter-to-large-world property matrix
  remain open.

## Not yet tested

- CPU 4D BVH/manual traversal and the adversarial watertight corpus.
- Runtime/stub benchmark manifests and deliberate corruption detection.
- Any actual Metal BLAS/TLAS build, shader trace, attribute reconstruction, or
  scale crossover.
- Cage authoring/LOD quality over representative animation clips.

## Blocked by environment

- Vulkan/NVIDIA and CUDA work: no Vulkan SDK/loader, NVIDIA GPU, `nvidia-smi`,
  or `nvcc`.
- Unreal integration: no pinned Unreal installation or source checkout.
- Cycles device integration: Blender 5.2.0 LTS is installed, but no pinned
  Cycles/Blender source checkout exists.
- RenderMan true integration: RenderManProServer 26.2 is installed, while the
  roadmap requires a separately pinned capability study and licensed prototype.

## Reproduction commands

```sh
cmake --preset dev
cmake --build --preset dev
ctest --preset dev
./build/dev/tetcage_metal_probe
./build/dev/tetcage_vulkan_probe
```

The Metal command must have direct GPU-driver access. If it returns zero devices
inside a sandbox, that result demonstrates the execution boundary rather than
absence of the physical Apple GPU.
