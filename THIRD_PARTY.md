# Third-party and research attribution

This is an independent implementation of the method described by:

Holger Gruen, Carsten Benthin, Michael Kern, and David McAllister,
“Ray Tracing Massive Amounts of Animated Geometry,” *Proceedings of the ACM on
Computer Graphics and Interactive Techniques* 9(4), Article 49, July 2026,
[DOI 10.1145/3820014](https://doi.org/10.1145/3820014).

The paper states a Creative Commons Attribution 4.0 license for the publication.
That license does not supply or license source code. No paper implementation is
copied into this repository.

The portable baseline currently depends only on C++20 and platform SDK headers.
Optional build targets use Apple Metal or Vulkan under their respective SDK and
platform terms. Later Unreal Engine, Blender/Cycles, NVIDIA CUDA/OptiX, and
RenderMan integrations must record pinned revisions and applicable licenses
before code is redistributed.

A focused patent/freedom-to-operate review remains a release gate and is not
replaced by this attribution file.
